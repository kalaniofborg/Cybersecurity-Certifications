> **Note:** All practical security exercises documented here are performed in controlled lab environments for educational purposes.

## About the Program

The **EC-Council Certified Cybersecurity Technician (CCT)** program focuses on developing foundational and practical cybersecurity skills.

The coursework covers areas such as:

* Cybersecurity fundamentals
* Networking
* Network security
* Vulnerability assessment
* Malware and malicious software
* System security
* Threats and attacks
* Security tools
* Digital forensics
* Incident response
* Security monitoring
* Defensive security techniques

The program combines **theory with hands-on laboratory exercises** to provide practical experience with cybersecurity concepts and tools.
